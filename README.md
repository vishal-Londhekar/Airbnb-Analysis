# 🏡 Airbnb Booking Trends Analysis – Tableau Dashboard

## 📌 Project Objective
To analyze Airbnb booking patterns across key regions using Tableau, enabling actionable insights for hosts, investors, and platform managers to optimize pricing, availability, and marketing strategies.

---

## 📊 Tools & Technologies
- ✅ Tableau (v2024.1)
- ✅ Data Prep: Excel / CSV
- ✅ Visualization: Interactive Dashboards, Heatmaps, KPI Cards, Filters

---

## 📂 Dataset Overview
- Source: [Inside Airbnb Open Data](http://insideairbnb.com/get-the-data/)
- Data Points: 45,000+ listings from cities like New York, San Francisco, Boston, and LA
- Features:
  - Room type (entire home, private room, shared room)
  - Price per night
  - Number of reviews
  - Minimum nights
  - Availability (365 days)
  - Neighborhood group

---

## 🔍 Analysis Highlights
1. **Room Type Performance**
   - Entire homes dominate pricing and revenue
   - Private rooms more budget-friendly, but high in volume

2. **Pricing & Revenue**
   - Price varies significantly by neighborhood group and city
   - Seasonality impacts occupancy rate

3. **Availability & Booking Patterns**
   - Central urban neighborhoods have higher year-round availability
   - Listings with more than 10 reviews tend to have better occupancy

4. **Geospatial Analysis**
   - Interactive map dashboard of listings by price and room type
   - Clustered analysis of hotspots by city
