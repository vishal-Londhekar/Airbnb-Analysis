# Airbnb Global Listings Analysis — Tableau

A Tableau business analytics project exploring Airbnb listing characteristics, pricing, availability, host activity, and geographic patterns.

## Overview

This project demonstrates how a packaged Tableau workbook can turn a listings dataset into an interactive analysis for hospitality and short-term-rental questions.

Typical questions explored include:

- Which neighbourhoods and property types have higher prices?
- How do availability and review activity vary across listings?
- Which hosts or listing segments appear most active?
- What geographic patterns are visible in the dashboard?

## Files

- **Airbnb Analysis_v2024.1.twbx** — packaged Tableau workbook
- **README.md** — project documentation

The repository currently contains the packaged workbook only. The workbook may include its data extract and presentation assets internally; the README does not treat those internal assets as separate repository files.

## Tools

Tableau Desktop or Tableau Reader, calculated fields, filters, maps, charts, and dashboard actions.

## How to view

1. Download **Airbnb Analysis_v2024.1.twbx**.
2. Open it with a compatible Tableau Desktop or Tableau Reader version.
3. If Tableau requests a data connection, follow the workbook's packaged-data instructions.
4. Use the dashboard filters and sheet navigation to explore the views.

## Limitations

- The repository does not include a separate raw-data file or extraction script.
- Results depend on the source snapshot embedded in the packaged workbook.
- The analysis is descriptive and should not be interpreted as a causal pricing model.
- Add the dataset source, collection date, and licence information if this project is published for wider reuse.
